# Видеодемонстрации

Автор проекта — Иван Лазичный. Автор проверил и утвердил код, золотой набор, калибровочные метки, результаты, отчёт и видеокомментарий. Подтверждение: [author_approval.json](../reports/submission/author_approval.json).

- `screencast.mp4` — основной скринкаст: новый вопрос к GigaChat, вызов поиска, цитаты и JSON, отсутствие сведений, попытка навязать инструкцию, основной benchmark и дополнительные эксперименты.
- `search-tools.mp4` — отдельная проверка `semantic_search` и `keyword_search` через нативный function calling с настоящими новыми API-вызовами.
- `*.vtt` — русские субтитры; они также включены в MP4 отдельной дорожкой.
- `recording-manifest.json` — фактические длительности, главы, SHA256 и идентификаторы новых запусков.
- `screencast-poster.png` — кадр реального ответа в первой записи.

Оба ролика — запись работающего локального браузерного интерфейса, а не набор нарисованных ответов. Вопросы при первой записи действительно отправлены в публичный API; новые вызовы сохраняются в `reports/submission/screencast_calls.jsonl`. Основные показатели качества взяты из отдельно обозначенного завершённого эксперимента, не вычислены по пяти демонстрационным запросам.

Озвучка — русский голос Milena. Текст авторского комментария сохранён в `docs/demo/narration.json` и проверен и утверждён Иваном Лазичным вместе с готовыми видеозаписями.

## Воспроизведение записи

Нужны Python 3.12+, зависимости проекта, macOS `say`, голос Milena и системные `ffmpeg`/`ffprobe`.

```bash
uv pip install --python .venv/bin/python -r requirements-media.txt
.venv/bin/python -m playwright install chromium
# Повтор сохранённых вызовов, с явной пометкой на экране; новых API-затрат нет:
.venv/bin/python scripts/record_screencast.py
# Новые оплачиваемые вызовы во время записи:
.venv/bin/python scripts/record_screencast.py --live
```

Для интерактивной демонстрации: `.venv/bin/python scripts/demo_server.py --live`, затем открыть `http://127.0.0.1:8765`. Без `--live` доступен просмотр отчётов; новые запросы запрещены. Сервер слушает только loopback, допускает не более 12 вопросов за сессию и не передаёт ключ в браузер.

Папка `.cache/recording/` содержит промежуточные аудио и видео локально и не входит в Git. В репозиторий включены итоговые MP4, субтитры и описание.
