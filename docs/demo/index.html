Как получен ответ
    
      
    
    
    

    
    
      
    Два способа найти свидетельство
    Один вопрос про IT-завтрак ПМЭФ-2016. Модель вызывает выбранную функцию, приложение выполняет поиск, ответ проходит проверку цитат.
    
      
    
      
    В этой демонстрации инструмент выбран принудительно. В обычном режиме выбор делает GigaChat.
    
      
    Выберите инструмент для живого вызова API.

      40 тестовых вопросов, каждый задан трижды. Конфигурация выбрана заранее на 20 вопросах разработки. Кеш готовых ответов выключен.

      Полезный ответ проходит проверки формата, обязательных фактов и источников. Расходы неудачных попыток входят в расчёт.
      Стоимость — оценка по тарифному профилю, не подтверждённое списание.
      
      
      Граница вывода. Доля полезных ответов на этом наборе: 70% → 70%. Это не доказательство отсутствия потерь на любых вопросах: 95% интервал разницы около −10…+10 процентных пунктов. В baseline есть три попытки с неизвестным расходом; его стоимость — нижняя граница.
      
    
      

    
      
      
      Дополнительные шаги имеют свою цену
      Продвинутые техники сравниваются с контролем на одинаковых вопросах. Отрицательные результаты сохраняются.
      
      
      ЭкспериментВопросовПолезность
      контроль → опыт      		Токены / вопрос
      контроль → опыт
      
      
      Self-consistency: три кандидата
      Согласие определяется по фактам и подтверждениям. На шести вопросах качество снизилось, а расход вырос — в итоговую конфигурацию техника не включена.
      ReAct: до трёх поисков
      Помог на шести составных вопросах. На четырёх вопросах, требующих нескольких фрагментов, прироста не дал. Этого недостаточно для общего вывода о пользе агента.
      
      
      Точный кеш проверен отдельным опытом: повтор вопроса возвращает сохранённый ответ без нового API-вызова. В основном сравнении эта экономия не используется.
      
    
      

    
      
      
      Что подтверждено проверками
      Принятый ответ проверяется до показа. Ошибки API и превышение бюджета сохраняются отдельно от ответа «нет сведений».
      
      
        Что важно учитывать
        Метрики получены автоматическим оценщиком.
        Золотой набор покрывает 15 из 30 стенограмм и чаще проверяет вступительные фрагменты. Итог ограничен этим набором.
        Полные исторические журналы заморожены. Новая диагностика и живые демонстрации не подменяют основной benchmark.
